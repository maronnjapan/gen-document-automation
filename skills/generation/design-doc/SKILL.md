# 設計書の構成

次の章立てを基本とし、不要な章は「該当なし」と書いて残す。

1. 概要: 目的、背景、対象範囲（スコープ外も明記）
2. 用語: 本書で使う用語の定義
3. 要件: 機能要件と非機能要件（性能・可用性・セキュリティ）
4. 全体構成: コンポーネントと責務、処理の流れ（Mermaid図を使ってよい）
5. 詳細設計: データ構造、インターフェース、エラー処理
6. 運用: 監視、障害対応、バックアップ
7. 未決事項・リスク: 決まっていないことと、その判断期限・担当

## 記載ルール

- 「なぜその設計にしたか」を、検討した代替案と比較して書く。
- 外部システムとのインターフェースは、入力・出力・エラー時の挙動を表で示す。
