# 運用手順書の構成

1. 目的と適用場面: どの状況でこの手順を使うか
2. 前提条件: 必要な権限、ツール、事前確認事項
3. 手順: 番号付きの操作手順。各手順に「実行するコマンド」と「期待される結果」を書く
4. 確認: 作業が成功したことの確認方法
5. 切り戻し: 失敗した場合に元に戻す手順
6. 連絡先・エスカレーション: 判断に迷ったときの連絡先

## 記載ルール

- 破壊的な操作（削除・再起動・本番反映）の前には、確認事項を太字で明記する。
- 環境ごとに値が変わる箇所は `<環境名>` のようなプレースホルダーで示す。
