# 日本語技術文書の文体ルール

- 文体は「です・ます」調に統一する。箇条書きの項目は体言止めでもよいが、1つのリスト内では揃える。
- 1文は60字程度までを目安にし、1文に1つの事柄だけを書く。
- 結論や要点を先に書き、理由・詳細は後に書く。
- 「など」「適宜」「いい感じに」のような曖昧な表現を避け、対象・条件・数値を具体的に書く。
- 用語は初出で定義し、以後は同じ表記を使う（例: 「ジョブ」と「タスク」を混在させない）。
- 手順は番号付きリストで書き、1ステップに1操作だけを書く。
- コマンド、設定値、ファイル名はインラインコードまたはコードブロックで示す。
